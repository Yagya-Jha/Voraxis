VORAXIS CHESS ENGINE — DETAILED DEVELOPMENT CHECKLIST

================================================================================
1. SEARCH ALGORITHMS
================================================================================

[x] 1.1 Minimax (COMPLETED)
    [x] Explore candidate moves recursively.
    [x] Assume both players choose moves that maximize their own outcome.
    [x] Evaluate positions at the search horizon (terminal/leaf nodes).
    [x] Return scores consistently from the perspective of the side to move.
    [x] Handle checkmate and draw scores separately from ordinary positional scores.

[x] 1.2 Negamax (COMPLETED)
    [x] Use the zero-sum property of chess to simplify Minimax.
    [x] Express each node’s score from the current side’s perspective: score = -negamax(...).
    [x] Keep score perspective consistent throughout search and evaluation.

[x] 1.3 Alpha-Beta Pruning (COMPLETED)
    [x] Maintain alpha (best score already guaranteed for side to move) and beta (opponent's cutoff bound).
    [x] Stop searching moves when score >= beta (beta cutoff).
    [x] Test against plain Minimax at shallow depths; node counts drop drastically but scores agree.

[x] 1.4 Iterative Deepening (COMPLETED)
    [x] Search depth 1, then 2, then 3, iteratively.
    [x] Retain the best move from the last completed iteration.
    [x] Allow search to stop safely when time or node limits expire.

[ ] 1.5 Principal Variation Search (PVS)
    - Search first move with full alpha-beta window [alpha, beta].
    - Search subsequent moves with null/zero window [alpha, alpha+1].
    - Re-search with full window only if a move proves superior.

[x] 1.6 Quiescence Search (COMPLETED)
    [x] Search beyond nominal horizon for tactical stability (captures, promotions).
    [x] Stand-pat evaluation threshold.
    [x] Avoid horizon effect.

[ ] 1.7 Aspiration Windows
    - Narrow initial window around previous iteration's score [score - delta, score + delta].
    - Re-search wider on fail-low or fail-high.

[ ] 1.8 Check Extensions
    - Extend search depth by 1 ply when in check.

[ ] 1.9 Late Move Reductions (LMR)
    - Search quiet moves late in the move list at reduced depth.
    - Re-search at full depth if they exceed alpha.

[ ] 1.10 Null Move Pruning
    - Pass turn to verify if opponent can still not breach beta.
    - Guard against zugzwang in late endgame.

[ ] 1.11 Futility Pruning
    - Prune hopeless quiet moves near leaf nodes if eval + margin < alpha.

[ ] 1.12 Razoring
    - Early quiescence drop at shallow pre-frontier nodes if eval is far below alpha.

[ ] 1.13 Singular Extensions
    - Extend search if the TT move is significantly better than all alternatives.

[ ] 1.14 Other Search Controls & Mate Distance Pruning
    - Maximum ply limit (e.g. 64 / 128).
    - Mate-distance scoring adjustments (closer mate is scored higher).
    - Node counters & search cancellation flag.
